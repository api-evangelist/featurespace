# Featurespace

Featurespace is an enterprise financial-crime prevention company founded in 2008 out of the University of Cambridge and acquired by Visa (announced September 2024). Its flagship ARIC Risk Hub applies Adaptive Behavioral Analytics and Automated Deep Behavioral Networks to risk-score events in real time — detecting payment fraud, scams, and money laundering while reducing false positives for banks, payment processors, merchant acquirers, insurers, and gaming operators. The platform processes 100bn+ events per year across 180+ countries.

Featurespace does not publish a public, unauthenticated developer API. Its ARIC documentation portal (docs.featurespace.com) is gated behind customer login, and the ARIC mobile SDKs are distributed under access request rather than public package registries. The public GitHub organization (github.com/Featurespace) hosts research-paper repositories only.
